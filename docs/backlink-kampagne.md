## 7. Nach jedem Eintrag: Dofollow prüfen
```
curl -sIL https://verzeichnis.de/dein-eintrag | grep -i "rel="
```
Kein `rel="nofollow"` in der Nähe deines Links = Dofollow (SEO-Wert). Vierteljährlich nachprüfen.
